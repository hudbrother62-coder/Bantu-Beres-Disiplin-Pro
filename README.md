# Bantu Beres Disiplin Pro

Web app responsif untuk pengelolaan disiplin sekolah.

## Stack
- Next.js 15
- React 19
- Supabase Auth/Postgres/Storage
- Vercel

## Prinsip
Satu akun mewakili satu sekolah dan memiliki akses penuh ke data sekolah tersebut. Isolasi data dilakukan dengan Row Level Security di Supabase.
